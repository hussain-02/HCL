\# Day 8 — Collections Part 2



\## Objective



Implement advanced Java Collections concepts in the Bus Ticket Reservation System.



\## Topics



\- Queue

\- Deque

\- PriorityQueue

\- Iterator

\- ListIterator

\- Comparable

\- Comparator

\- Sorting



\## Project Scenario



The reservation system requires:



\- Passenger waiting queue

\- Priority passengers

\- Boarding queue

\- Bus sorting

\- Collection traversal



\## Data Structures



| Requirement | Collection |

|---|---|

| Waiting passengers | Queue |

| Priority passengers | PriorityQueue |

| Add/remove from both ends | Deque |

| Safe traversal/removal | Iterator |

| Custom sorting | Comparator |



\## Sorting



Buses can be sorted by:



\- Bus number

\- Seat capacity

\- Fare



\## Expected Outcome



\- Understand Queue and Deque.

\- Use PriorityQueue.

\- Use Iterator.

\- Use Comparator.

\- Sort custom objects.

\- Select the appropriate collection.
